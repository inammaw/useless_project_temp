### Project Description
[2-3 lines about what your project does]
Tharavadu 95 is a retro Windows 95 simulator set in a Kerala household. Powered by AMMA_KERNEL.SYS, it tracks chores, screen time and PSC prep. Keep Amma’s stress below 100% or face the dreaded BSOD. With Malayalam Manglish, Kerala-inspired visuals and nostalgic sounds, chaos becomes a survival game
